SCAPES generation: autoregressive and atoms

Three keys set the generation geometry: codec, conditioning_rate (Hz) and conditioning_memory_seconds. The default rate is 10 Hz for every codec. The requested rate is rounded to the nearest available rate (ties go to the smaller n), and a startup line prints the resolved geometry and one warning line per adjustment. This page is generated from the resolver, so it cannot disagree with the code.

Autoregressive

Causal codecs generate one block of n latents per step and attend to the last W latents. W = min(m, 300), raised to n if the memory is shorter than a block.

Atoms

Non-causal codecs generate one atom per step. Its first o latents are zeroed, the next x are crossfaded with the previous atom, and the last n are new. The buffer holds K past atoms, each shifted by n.

Formulas

x = min(⌈n/2⌉, xdef)
o = max(n, Amin − x − n)
A = o + x + n
m = ⌈latent rate × memory seconds⌉ latents; K = smallest K ≥ 1 with m ≤ x + K·n
n = the n between nmin and nmax that minimises |latent rate / n − requested rate|
cap: K·A ≤ 300, else K = Kmax = ⌊300/A⌋; W ≤ 300

The cap is 300 attended latents for every codec. A request is snapped to the nearest available rate in Hz. Each n owns the explicit range [low, high) Hz given by rate_range (the midpoints to the neighbouring rates; a midpoint goes to the smaller n). A request above the range of nmin resolves to nmin, the fastest rate, and one below the range of nmax to nmax, the slowest. Every snapped request carries the note snapped. nmax is the largest n with A ≤ 300 for atoms and 300 for autoregressive.

The window

The window is one replaceable function, crossfade_window in SCAPES/data/geometry.py: zeros, a rise of equal power (sine), ones, and the matching fall (cosine), so rise² + fall² = 1. Changing the window means editing only that function.
