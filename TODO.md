## Must do
1. **Retrain the four codecs on the new geometry** (encodec24, spectrostream, encodec48, music2latent), small size, microtex, `conditioning_rate = 10`, `conditioning_memory_seconds` 1 for autoregressive and 0.5 for atoms. Old checkpoints are not loadable (no backward compatibility), so every model is retrained. Then listen and evaluate with the teacher-forced and free-running paths.
2. **Pick the batch size from the GPU.** Before training, measure the GPU memory of the machine (for example `torch.cuda.mem_get_info()`) and choose the largest `batch_size` that fits, instead of a fixed value. The same idea applies to the dataprep encode batch (`scripts` and `SCAPES/data/dataprep/atoms.py` use a sample budget now); Music2Latent dataprep peaked at 16.4 GiB on the RTX 4090 with a batch of 128 at one new latent, so a smaller batch may be enough.
3. **Rewrite or delete `scripts/measure_rtf.py`.** It still builds two modes per codec (old design), and its `--gin-dir` default points to a folder that no longer exists. Real-time factors should be measured per codec with the three keys, with and without classifier-free guidance. Its known-answer statistics test passes; the end-to-end JSON test was removed.
